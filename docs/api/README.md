# Cafe Vitrin Dokümantasyon

**Cafe Vitrin**, kafe ve restoran uygulamaları için özelleştirilebilir, modern arayüz bileşenleri sunan bir Flutter kütüphanesidir. 

Bu paket, daha önce açık kaynak kodlu olan e-ticaret widget kütüphanesinden çatallanarak (fork) kafeler için tamamen özel bir yapıya büründürülmüştür. İçerisindeki tüm renkler, ikonlar, resimler ve yazılar parametrik olarak dışarıdan ayarlanabilir.

## Kurulum

`pubspec.yaml` dosyanıza paketi ekleyin:

```yaml
dependencies:
  cafe_vitrin: ^1.0.4
```

Ardından terminalde çalıştırın:
```bash
flutter pub get
```

## Canlı Özelleştirici (Live Builder)

Cafe Vitrin paketinin sunduğu tüm widget'ları anlık olarak tarayıcı üzerinde özelleştirebilirsiniz. Canlı özelleştirici ile uygulamanızın **tema rengini**, **ikon URL'lerini** ve **görsel yapılarını** test edebilir, istediğiniz tasarımı saniyeler içinde oluşturabilirsiniz.

👉 **[Canlı Yapılandırıcıya Git](https://sebinc14.github.io/cafe_vitrin/)**

Sol menüden tüm widget'ların detaylarını inceleyebilirsiniz.
