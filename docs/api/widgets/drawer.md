# Custom Drawer & Profile

Kullanıcı profilini ve sadakat puanlarını (Yıldızlarını), hesap hareketlerini barındıran gizli menüdür (sol üstteki sandviç ikonundan açılır).

Özelleştirilebilen alanlar:
- **User Name**: Kullanıcı adı
- **Email**: E-posta adresi
- **Points/Stars**: Kullanıcının topladığı puanlar
- **Table Number**: Kullanıcının oturduğu masa numarası
